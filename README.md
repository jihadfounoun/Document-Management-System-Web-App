# Document Management System

### Overview

This project was developed as part of the *Informatic Technologies for the Web* course at Politecnico di Milano during the academic year 2023-2024. It is a web-based solution for managing documents and folders, implemented in two versions:

- **Pure HTML version**: Server-side rendering with Thymeleaf.
- **RIA version**: Client-server architecture with JavaScript and AJAX.

### Objective

Design and implement a secure web application for managing documents and folders, ensuring data integrity with validation on both client and server sides.

## Repository Structure

The repository consists of a `dump` folder with the MySQL schema export for the database, the `file_system_ria` directory containing the RIA version, and the `file_system_pure_html` directory containing the pure HTML version.



### Technology Stack

- **Backend**: Java Servlets with DAO pattern for MySQL.
- **Frontend**: Thymeleaf templates (HTML version) and JavaScript/AJAX (RIA version).
- **Database**: MySQL.

### Tools Used

- **Eclipse IDE**: Development and debugging.
- **Apache Tomcat**: Server deployment.
- **MySQL Workbench**: Database management.
- **Postman**: API testing.
